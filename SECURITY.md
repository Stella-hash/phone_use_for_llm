# Security reporting

Maintainer: [Stella-hash](https://github.com/Stella-hash). This project is distributed
as public GitHub source; no production-safe release or response-time guarantee
is claimed.

GitHub private vulnerability reporting is enabled. Use **Report a vulnerability**
on the repository's [Security Advisories page](https://github.com/Stella-hash/phone_use_for_llm/security/advisories)
to send a private report. If the button is unavailable, do not post security
details to an issue;
ask the maintainer to provide a private reporting route without including details.

Reports should contain the affected commit, expected/observed boundary, platform
and a minimal synthetic test description. Exclude credentials, device screenshots,
private logs, household addresses, real targets and exploit chains. Test only
disposable synthetic fixtures or separately authorized isolated environments.

Security fixes target `main`. Coordinate disclosure with the maintainer and an
independent reviewer to assess the affected boundary and exact repaired commit
before publishing details. The [deployment boundary](SAFETY.md) applies in every profile.
